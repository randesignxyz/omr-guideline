# OMR Ordering Guideline

A standalone, responsive Khmer HTML infographic for One More Restaurant.

## Preview

Open `index.html` in a browser. No build step is required.

- Eight-step ordering guide with AD Account Yes/No branches.
- Editable/selectable Khmer text and responsive green/yellow styling.
- Upload header artwork and step illustrations directly from your device.
- Save HTML copy embeds uploaded images in the downloaded file.
- Download PDF opens the browser print dialog; select Save as PDF.

Noto Sans Khmer loads from Google Fonts when available, with local Khmer font fallbacks. Uploads are processed locally in the browser.
